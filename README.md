# fMRI-data-analysis-with-python
This project implements a reproducible resting-state fMRI preprocessing and functional connectivity pipeline using Python and Nilearn, demonstrated on a subset of the ADHD-200 dataset(Nitrc adhd resting-state dataset. ftp://www.nitrc.org/fcon_1000/htdocs/indi/adhd200/sites/ADHD200_40sub_preprocessed.tgz. Accessed: 2021-05-19.)
.  The workflow is organized into two independent stages: fMRI preprocessing and Functional Connectivity Analysis
